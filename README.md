# cryptotriv.github.io

Personal portfolio site for Triv, an MEV searcher.

## Tech stack

- Astro
- Tailwind CSS v4
- TypeScript
- Deployed to GitHub Pages

## Local development

- `npm install` — install dependencies
- `npm run dev` — start the local dev server
- `npm run build` — build the production site to `dist/`
- `npm run check` — run Astro and TypeScript diagnostics

## Deployment

Pushes to `main` auto-deploy to GitHub Pages via the GitHub Actions workflow.

`scripts/og-card.html` is the source for the Open Graph image at `public/images/og-card.png`.
